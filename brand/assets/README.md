# Rightroom brand kit

The icon is Dan's supplied drawing (`rightroom-icon.svg`, Electric Blue `#0057FF`). The wordmark is
"rightroom" in Geist at weight 800 with −0.045em letter-spacing, converted to outlines so the SVGs
open the same in any design tool.

| File | Use |
|---|---|
| `rightroom-icon.svg` · `-white.svg` · `-black.svg` | The icon alone |
| `rightroom-logo.svg` | Icon + wordmark on light backgrounds |
| `rightroom-logo-on-dark.svg` | Blue icon + white wordmark on dark backgrounds |
| `rightroom-logo-white.svg` | All white, for use on Electric Blue or photos |
| `rightroom-logo-2000.png`, `rightroom-icon-1024.png` | PNG versions (transparent) |
| `rightroom-app-icon-1024.png` | White icon on blue, for app stores and avatars |
| `x-profile-400.png` | X profile picture |
| `x-banner-1500x500.png` | X header (text kept clear of the profile photo area) |
| `og-1200x630.png` | Link-preview image (also served as `/og.png`) |

Web icons served by the site live in `site/` (favicons, Apple touch icon, app icons, manifest).
